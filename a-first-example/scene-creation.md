# Scene creation

Create a new Unity project using the _**Universal 3D**_**&#x20;template**, and call it **Ball vs Blocks**

* From the top menu: **File → New Scene -> Basic (URP)**
* Remove any leftover assets from previous scenes.
* Press **Ctrl/Cmd + S** and save it as `Scene_1` in the **Scenes** folder.

{% hint style="info" %}
Another approach is to rename the existing `SampleScene` to `Scene_1`, so you needen't create a new scene.
{% endhint %}
